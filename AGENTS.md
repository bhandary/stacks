# Stacks

Personal book shelf. UI lives in `src/components`, persistence in `src/lib/db.ts` + `src/lib/books.ts`, ISBN import in `src/lib/lookup.ts`. Sign-in is Google OpenID Connect via Auth.js; each account has its own shelf (`AUTH.md`). Manual backup and restore is documented in `BACKUP.md`. Verify with `.cursor/skills/verify-stacks`.
